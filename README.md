# Autoencoder — Reconocimiento de Dígitos en Imágenes Borrosas

Red neuronal (autoencoder) capaz de reconocer imágenes borrosas de dígitos y predecir a qué número corresponden.

## Contenido

- `autocodificador.ipynb` — notebook con la construcción y entrenamiento de la red.
- Notebook también disponible en [Google Colab](https://colab.research.google.com/drive/172tddiv1RlcXQJQXHZnVSRKpMrWgKUPP?hl=es).

## Tecnologías

Python · TensorFlow · pandas · NumPy · Matplotlib

## Cómo ejecutar

```bash
pip install tensorflow pandas numpy matplotlib jupyter
jupyter notebook autocodificador.ipynb
```
